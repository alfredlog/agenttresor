Connect an AgentTresor agent

Run this once on the agent's own machine, in a checkout of this project (npm install once). The code works once, for 10 minutes.

No connection code in this link.

It connects the agent (its settings and its own signing key go to mcp-data/agents/<agentId>/), runs the agent service, sets up Claude Code and prints the key's fingerprint: check that fingerprint on the vault page before funding the agent. Then open a new Claude Code session in that folder.
